# برنامج وتطبيق «الورد القرآني» — رفيقك اليومي للقرآن الكريم 📖✨

تطبيق وبرنامج قرآني حديث متكامل (PWA & Web) مخصص لقراءة وحفظ وتدبر القرآن الكريم، وتثبيت الحفظ عبر التكرار الذكي والتلاوات العطرة بأصوات كبار قراء العالم الإسلامي.

---

## 🌟 أبرز مميزات برنامج الورد القرآني

1. **وِرْد القراءة اليومي (604 صفحة من مصحف المدينة الشريف)**:
   - عرض صفحات المصحف الشريف بخط الرسم العثماني ومصحف المدينة المنورة العالي الدقة (QCF4).
   - إمكانية تحديد ورد القراءة اليومي بسهولة (صفحة، صفحتين، 4 صفحات، جزء كامل، أو عدد مخصص).
   - شريط تقدم ذكي مع متابعة الإنجاز اليومي ومعدل الاستمرار (Streak) بدون انقطاع.
   - حفظ تلقائي لموضع التوقف ووضع الفواصل المرجعية (Bookmarks).
   - مؤثرات صوتية طبيعية وواقعية لتقليب الصفحات وعند إتمام الورد اليومي.

2. **وِرْد الحفظ وتثبيت الآيات (المُكرِّر الذكي)**:
   - التبديل السلس بين «وِرد القراءة» و«وِرد الحفظ».
   - **عداد التكرار التفاعلي**: زر سريع لتكرار قراءة الآية وتثبيتها في الذاكرة (3، 5، 7، 10، 15، 20 مرة أو أكثر) مع صوت نقر ونغمة إنجاز عند اكتمال التكرار.
   - **خاصية اختبار الاسترجاع (إخفاء النص)**: إخفاء نص الآيات لاختبار الحفظ غيباً، مع زر لإظهار النص للتأكد.

3. **المشغل الصوتي وتلاوات كبار القراء**:
   - الاستماع المباشر للآيات أو السور بأصوات نخبة من كبار قراء العالم الإسلامي:
     - الشيخ مشاري راشد العفاسي
     - الشيخ محمود خليل الحصري (المصحف المرتل والمعلم)
     - الشيخ محمد صديق المنشاوي
     - الشيخ عبد الباسط عبد الصمد
     - الشيخ عبد الرحمن السديس
     - الشيخ سعود الشريم
     - الشيخ ماهر المعيقلي
     - الشيخ ياسر الدوسري
     - الشيخ أحمد بن علي العجمي
     - الشيخ سعد الغامدي
   - ميزة تكرار تلاوة الآية تلقائياً للمساعدة في الحفظ المتقن.

4. **نمط الورد القرآني للأطفال والبراعم (Kids Mode)**:
   - واجهة مخصصة تفاعلية وجذابة للأطفال والناشئة لتعلم قصار السور.
   - اختبارات تفاعلية، أصوات تشجيعية، ونقاط ومكافآت يومية لتحفيزهم على حفظ كتاب الله.

5. **نظام التذكيرات اليومية الذكية**:
   - ضبط موعد التذكير بالساعة والدقيقة للورد اليومي.
   - إشعارات منبثقة عبر متصفح الهاتف أو الكمبيوتر مع نغمات تنبيه هادئة لتذكيرك في الموعد المحدد.

6. **تصميم فاخر وعصري (Dark Imperial Luxury)**:
   - ألوان ملكية فاخرة (الزمردي الداكن والأسود النقي مع لمسات الذهب العربي الأصيل).
   - خطوط عربية كلاسيكية أصيلة (رقعة، نسخي، أميري).

7. **تطبيق ويب تقدمي مستقل (PWA) وتطبيق هاتف (Android APK)**:
   - يعمل على كافة المتصفحات والأجهزة دون الحاجة لبرامج مساعدة.
   - يمكن تثبيته كأيقونة تطبيق على الشاشة الرئيسية للهواتف الذكية (Android و iOS).
   - حزمة تطبيق أندرويد جاهزة عبر Capacitor.

---

## 🛠️ التقنيات المستخدمة

- **React 19** & **Vite** — لأعلى سرعة وأداء سلس واستجابة فورية.
- **Lucide Icons** — أيقونات عصرية فائقة الوضوح.
- **Capacitor 8** — لتشغيل التطبيق كتطبيق أندرويد وiOS أصلي.
- **QCF Quran Fonts & Al-Quran Cloud APIs** — لنصوص وتلاوات القرآن الكريم.

## 🚀 طريقة التشغيل والتطوير

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر المحلي:
```bash
npm run dev
```

### 3. بناء نسخة الإنتاج:
```bash
npm run build
```
